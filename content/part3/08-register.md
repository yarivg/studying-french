# Register: familier, courant, soutenu

French is unusually stratified. The same idea has three recognisable versions, and using the
wrong one is a social error rather than a grammatical one. Most textbooks teach only the middle
layer, which is why learners often sound simultaneously correct and slightly odd.

| Register | Where it lives |
|---|---|
| **soutenu** | literature, formal writing, speeches, official correspondence |
| **courant** | the default: news, work email, conversation with strangers |
| **familier** | friends, family, informal speech, texting |
| **argot / vulgaire** | slang; some of it is fine among friends, some is genuinely rude |

## The same sentence, three ways

| Soutenu | Courant | Familier |
|---|---|---|
| *Je ne sais pas.* | *Je ne sais pas.* | *J'sais pas.* / *Chais pas.* |
| *Je suis fatigué.* | *Je suis fatigué.* | *J'suis crevé.* |
| *Cela ne me convient point.* | *Ça ne me va pas.* | *Ça m'va pas.* |
| *Il est fort agréable.* | *Il est très sympathique.* | *Il est trop sympa.* |
| *Une automobile.* | *Une voiture.* | *Une bagnole.* |
| *Un travail.* | *Un travail.* | *Un boulot.* |
| *Un homme.* | *Un homme.* | *Un mec.* / *Un type.* |
| *Une femme.* | *Une femme.* | *Une meuf.* / *Une nana.* |

## What changes in familier French

### 1. ne disappears

::: examples
Je ne sais pas. → J'sais pas. ||
Ce n'est pas grave. → C'est pas grave. ||
Il n'y a personne. → Y'a personne. ||
:::

### 2. Questions lose inversion and est-ce que

::: examples
Où allez-vous ? → Tu vas où ? ||
Qu'est-ce que tu fais ? → Tu fais quoi ? ||
Combien ça coûte ? → Ça coûte combien ? ||
:::

### 3. on replaces nous

::: examples
Nous allons au cinéma. → On va au ciné. ||
Nous avons mangé. → On a mangé. ||
:::

### 4. Vowels and syllables get swallowed

| Written | Spoken |
|---|---|
| tu as | *t'as* |
| tu es | *t'es* |
| il y a | *y'a* |
| il faut | *faut* |
| je suis | *chuis* |
| celui-là | *ç'ui-là* |
| s'il te plaît | *steuplaît* |
| qu'est-ce que | *keske* |

### 5. Words get shortened

| Full | Short |
|---|---|
| le cinéma | le ciné |
| l'appartement | l'appart |
| le restaurant | le resto |
| la télévision | la télé |
| l'ordinateur | l'ordi |
| sympathique | sympa |
| le professeur | le prof |
| le petit déjeuner | le p'tit déj |
| d'accord | d'acc |
| après-midi | aprèm |
| la climatisation | la clim |

::: note This shortening is completely standard
*Sympa*, *télé*, *resto* and *prof* are so normal that the full forms sound stiff. They are not
slang — they are simply how the words are said.
:::

These are safe among friends and colleagues you know.

| Familier | Courant | English |
|---|---|---|
| le boulot | le travail | work, job |
| bosser | travailler | to work |
| la bagnole | la voiture | car |
| le mec | l'homme | guy |
| la meuf | la femme | woman |
| le pote | l'ami | mate, buddy |
| le gosse | l'enfant | kid |
| la clope | la cigarette | cigarette |
| le truc | la chose | thing, whatever |
| sympa | sympathique | nice |
| chouette | agréable | nice, great |
| marrant | drôle | funny |
| crevé | épuisé | exhausted |
| bouffer | manger | to eat |
| kiffer | aimer beaucoup | to love, to be into |
| s'éclater, se marrer | s'amuser | to have a great time |

::: examples
Ça te dit d'aller bouffer un truc ? || Fancy going for a bite?
J'ai un boulot de dingue en ce moment. || I've got an insane amount of work on.
On s'est bien marrés hier soir. || We had a great time last night.
Laisse tomber, c'est pas grave. || Forget it, it doesn't matter.
:::

## Verlan

A slang formed by reversing syllables. It is generational — strongly associated with younger
speakers and the *banlieues* — and it moves fast.

| Verlan | From | Meaning |
|---|---|---|
| **chelou** | louche | shady, weird |
| **relou** | lourd | annoying, heavy going |
| **chanmé** | méchant | awesome |
| **cimer** | merci | thanks |
| **téma** | mate | check it out |
| **pécho** | choper | to pull, to grab |
| **ouf** | fou | insane, amazing |
| **meuf** | femme | woman |
| **keuf** | flic | cop |
| **relou** | lourd | annoying |

::: warning Understand verlan; think twice before using it
Verlan is tightly bound to age, place and group. Used by an outsider it can sound like
imitation rather than fluency. *Meuf*, *ouf* and *relou* have crossed into general familiar
speech and are safe enough; the rest is worth recognising and leaving alone unless you are
firmly inside the group that uses it.
:::

## Expressions worth knowing

| Expression | Meaning | Register |
|---|---|---|
| **avoir le seum** | to be gutted | familier |
| **c'est ouf** | that's insane | familier |
| **ça craint** | that sucks | familier |
| **j'en ai marre** | I'm fed up | familier but very common |
| **ras-le-bol** | fed up | familier |
| **c'est nul** | that's rubbish | familier |
| **du coup** | so, as a result | courant, extremely frequent |
| **quand même** | still, all the same | courant |
| **carrément** | totally | courant / familier |
| **grave** | totally, seriously | familier |
| **au calme / oklm** | chill | familier, young |
| **bg** (beau gosse) | good-looking | familier, young |
| **tarpin** | very | regional (Marseille) |

::: warning Genuinely rude
*La gueule*, *le cul*, *bordel*, *le chiant*, *putain*, *merde* are vulgar. *Putain* in
particular is so frequent in casual French that it can seem harmless — it is not, in any
professional or unfamiliar setting.

*Ta gueule* (shut up) is aggressive. The neutral form is *tais-toi*.
:::

## What soutenu looks like

You will read this far more than you will write it.

| Feature | Example |
|---|---|
| passé simple | *Il **entra** dans la pièce.* |
| imperfect subjunctive | *Bien qu'il **fût** tard…* |
| inversion in questions | *Que **pensez-vous** de cela ?* |
| *ne* explétif | *avant qu'il **ne** parte* |
| *nous* rather than *on* | *Nous **avons** décidé…* |
| formal vocabulary | *débuter* for *commencer*, *demeurer* for *rester*, *convier* for *inviter* |
| *veuillez* + infinitive | *Veuillez agréer…* |

::: examples
Veuillez agréer, Madame, l'expression de mes salutations distinguées. || The standard formal letter closing.
Je vous prie de bien vouloir m'excuser. || Formal apology.
Dans l'attente de votre réponse. || Awaiting your reply.
:::

## Choosing your register

::: rule Match the person, not the topic
- **Stranger, older person, any professional context** → *vous*, courant, full *ne*.
- **Friend, peer, family** → *tu*, familier, dropped *ne*.
- **Writing anything official** → soutenu vocabulary, complete grammar, no contractions.

The safest default while learning is **courant with vous**. It is never wrong, only slightly
formal, and French speakers will invite you downwards with *on peut se tutoyer*.
:::

::: warning Mixing registers is the giveaway
*Veuillez me filer une clope* — combining the most formal imperative in French with slang for
*give me a cigarette* — is the kind of sentence that marks a learner instantly. Pick a level
and stay on it.
:::

## Practice

::: exercise Move it to familier
Je ne sais pas. || J'sais pas.
Ce n'est pas grave. || C'est pas grave.
Où allez-vous ? || Tu vas où ?
Nous allons au cinéma. || On va au ciné.
Il n'y a personne. || Y'a personne.
Qu'est-ce que tu fais ? || Tu fais quoi ?
:::

::: exercise Move it to courant
J'ai un boulot de dingue. || J'ai beaucoup de travail.
Il est trop sympa. || Il est très sympathique.
On s'est bien marrés. || Nous nous sommes bien amusés.
Ça craint. || Ce n'est pas bien. / C'est dommage.
Laisse tomber. || Abandonne. / Ce n'est pas grave.
:::

::: exercise Decode the verlan
chelou || louche — shady, weird
relou || lourd — annoying
cimer || merci
ouf || fou — insane
meuf || femme
téma || mate — check it out
:::

::: exercise Which register?
*Veuillez agréer mes salutations.* || Soutenu — formal letter.
*J'sais pas, moi.* || Familier.
*Je ne sais pas.* || Courant (or soutenu in writing).
*C'est ouf !* || Familier, young.
*Nous avons décidé de reporter la réunion.* || Courant to soutenu — professional.
:::

::: exercise Spot the mismatch
*Veuillez me filer une clope.* || Formal imperative + slang. Either *veuillez me donner une cigarette* or *file-moi une clope*.
*Ta gueule, s'il vous plaît.* || Aggressive slang + formal politeness. Say *taisez-vous, s'il vous plaît*.
:::
