# Verbs + à / de + infinitive

When one verb governs another, French inserts **à**, **de**, or nothing at all. There is no rule
— it is a property of each verb, and it rarely matches English. This chapter is a set of lists
to be learned in chunks, plus the patterns that make the chunks smaller.

::: rule The three groups
- **verb + infinitive** — no preposition: *je veux **partir***
- **verb + à + infinitive**: *j'apprends **à** nager*
- **verb + de + infinitive**: *j'essaie **de** comprendre*
:::

## Group 1: no preposition

Mostly verbs of wanting, being able, liking, moving and perceiving.

| Verb | Example |
|---|---|
| **vouloir** | *Je veux partir.* |
| **pouvoir** | *Je peux venir.* |
| **devoir** | *Je dois travailler.* |
| **savoir** | *Je sais nager.* |
| **aller** | *Je vais manger.* |
| **venir** | *Viens manger.* |
| **falloir** | *Il faut partir.* |
| **aimer** | *J'aime lire.* |
| **adorer** | *J'adore voyager.* |
| **détester** | *Je déteste attendre.* |
| **préférer** | *Je préfère rester.* |
| **espérer** | *J'espère venir.* |
| **penser** | *Je pense partir demain.* |
| **compter** | *Je compte y aller.* |
| **oser** | *Je n'ose pas demander.* |
| **sembler / paraître** | *Il semble dormir.* |
| **laisser** | *Laisse-moi passer.* |
| **faire** | *Je fais réparer la voiture.* |
| **voir / entendre / sentir / regarder / écouter** | *Je l'ai vu partir.* |

::: warning savoir vs pouvoir + infinitive
*Je **sais** nager* — I know how to swim (a learned skill).
*Je **peux** nager* — I'm able to swim right now (circumstances allow).
:::

## Group 2: verb + à + infinitive

Often verbs of starting, continuing, learning, helping and succeeding — a sense of movement
towards something.

| Verb | Example |
|---|---|
| **apprendre à** | *J'apprends à conduire.* |
| **commencer à** | *Il commence à pleuvoir.* |
| **continuer à** | *Continue à travailler.* |
| **se mettre à** | *Il s'est mis à pleurer.* |
| **arriver à** | *Je n'arrive pas à comprendre.* |
| **réussir à** | *Il a réussi à finir.* |
| **aider à** | *Il m'aide à porter ça.* |
| **hésiter à** | *J'hésite à lui dire.* |
| **penser à** | *Pense à fermer la porte.* |
| **chercher à** | *Il cherche à comprendre.* |
| **s'habituer à** | *Je m'habitue à vivre ici.* |
| **s'attendre à** | *Je m'attends à réussir.* |
| **inviter à** | *Il m'a invité à dîner.* |
| **encourager à** | *Elle m'encourage à continuer.* |
| **renoncer à** | *J'ai renoncé à comprendre.* |
| **passer du temps à** | *Je passe mon temps à lire.* |

::: warning arriver à = to manage to
*Je n'**arrive pas à** comprendre* — I can't manage to understand. This is one of the most
useful phrases in conversational French and nothing about *arriver* (to arrive) predicts it.
:::

## Group 3: verb + de + infinitive

The largest group. Often verbs of stopping, trying, deciding, asking and feeling.

| Verb | Example |
|---|---|
| **essayer de** | *J'essaie de comprendre.* |
| **décider de** | *J'ai décidé de partir.* |
| **arrêter de** | *Arrête de parler !* |
| **cesser de** | *Il n'a pas cessé de pleuvoir.* |
| **finir de** | *J'ai fini de manger.* |
| **oublier de** | *J'ai oublié de t'appeler.* |
| **refuser de** | *Il refuse de venir.* |
| **accepter de** | *Elle a accepté de m'aider.* |
| **choisir de** | *J'ai choisi de rester.* |
| **éviter de** | *Évite de faire ça.* |
| **risquer de** | *Tu risques de tomber.* |
| **venir de** | *Je viens de manger.* |
| **avoir besoin de** | *J'ai besoin de dormir.* |
| **avoir envie de** | *J'ai envie de sortir.* |
| **avoir peur de** | *J'ai peur de tomber.* |
| **avoir le temps de** | *Je n'ai pas le temps de finir.* |
| **être content de** | *Je suis content de te voir.* |
| **être obligé de** | *Je suis obligé de partir.* |
| **se souvenir de** | *Je me souviens de l'avoir vu.* |
| **rêver de** | *Je rêve de voyager.* |
| **mériter de** | *Tu mérites de réussir.* |
| **promettre de** | *Il a promis de venir.* |
| **s'occuper de** | *Je m'occupe de réserver.* |

::: rule Every "avoir + noun" expression takes de
*avoir besoin **de***, *avoir envie **de***, *avoir peur **de***, *avoir le temps **de***,
*avoir l'intention **de***, *avoir raison **de***, *avoir honte **de***.

Same for *être + adjective*: *être content **de***, *être capable **de***, *être obligé **de***,
*être sûr **de***.
:::

## Verbs that take both — with a change of meaning

| Verb | + à | + de |
|---|---|---|
| **commencer** | *commencer à faire* — start doing | *commencer par faire* — start by doing |
| **continuer** | *continuer à* — carry on | *continuer de* — same, slightly more formal |
| **décider** | *se décider à* — make up one's mind | *décider de* — decide |
| **demander** | *demander à faire* — ask to do (yourself) | *demander à qqn de faire* — ask someone to do |
| **penser** | *penser à faire* — remember to do | *penser faire* — intend to do |
| **venir** | *venir faire* — come to do | *venir de faire* — have just done |

::: examples
Il commence à pleuvoir. || It's starting to rain.
Commençons par le début. || Let's start with the beginning.
Je pense à fermer la porte. || I'm remembering to shut the door.
Je pense partir demain. || I'm thinking of leaving tomorrow.
Je viens manger. || I'm coming to eat.
Je viens de manger. || I've just eaten.
:::

## The two-object pattern

Several very common verbs take a **person with à** and a **thing with de**:

> **verb + à quelqu'un + de faire quelque chose**

| Verb | Example |
|---|---|
| **dire à … de** | *Je lui ai dit de partir.* |
| **demander à … de** | *Je lui ai demandé de venir.* |
| **conseiller à … de** | *Il m'a conseillé de partir.* |
| **permettre à … de** | *Il m'a permis de sortir.* |
| **interdire à … de** | *Il m'a interdit de fumer.* |
| **promettre à … de** | *Je lui ai promis de venir.* |
| **proposer à … de** | *Il m'a proposé de rester.* |
| **reprocher à … de** | *Il me reproche d'être en retard.* |

::: warning The person is always indirect here
*Je **lui** ai dit de partir* — not *je l'ai dit*. Because the structure is *dire **à**
quelqu'un*, the pronoun must be **lui / leur**.

This catches people constantly with *demander*, *dire* and *conseiller*, because English treats
those objects as direct: *I asked **him** to come.*
:::

## Prepositions before nouns can differ

The preposition a verb takes before an **infinitive** is not always the one it takes before a
**noun**.

::: examples
Je commence à travailler. || + infinitive: à
Je commence le travail. || + noun: nothing
Je joue au tennis. || jouer à + a game
Je joue du piano. || jouer de + an instrument
Il pense à son travail. || penser à + a noun
Il parle de son travail. || parler de + a noun
:::

::: warning Verbs that take no preposition in French but do in English
*attendre* quelqu'un — wait **for**
*chercher* quelque chose — look **for**
*écouter* quelqu'un — listen **to**
*regarder* quelque chose — look **at**
*demander* quelque chose — ask **for**
*payer* quelque chose — pay **for**

*J'attends le bus*, never *j'attends pour le bus*.
:::
