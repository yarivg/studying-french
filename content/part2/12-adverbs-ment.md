# Making adverbs in -ment

French builds adverbs from adjectives the way English uses **-ly**. The suffix is **-ment**, and
the rule for attaching it is almost entirely mechanical.

## The basic rule

> Take the **feminine** form of the adjective, add **-ment**.

| Adjective (m.) | Feminine | Adverb |
|---|---|---|
| lent | lente | **lentement** |
| heureux | heureuse | **heureusement** |
| doux | douce | **doucement** |
| franc | franche | **franchement** |
| sérieux | sérieuse | **sérieusement** |
| premier | première | **premièrement** |
| naturel | naturelle | **naturellement** |
| certain | certaine | **certainement** |
| complet | complète | **complètement** |
| actif | active | **activement** |

::: rule Always go through the feminine
*heureux* → *heureuse* → *heureusement*, not *heureuxment*. Building the feminine first makes
the whole system work without exceptions in this group.
:::

## Adjectives already ending in a vowel

If the **masculine** already ends in a vowel, add **-ment** directly — no feminine needed.

| Adjective | Adverb |
|---|---|
| vrai | **vraiment** |
| poli | **poliment** |
| absolu | **absolument** |
| rapide | **rapidement** |
| facile | **facilement** |
| probable | **probablement** |
| calme | **calmement** |

::: warning A few take an accent instead
*précis → **précisément***, *énorme → **énormément***, *profond → **profondément***,
*aveugle → **aveuglément***. The **é** replaces the vowel that would otherwise be silent.
:::

## Adjectives in -ant and -ent

These swap the ending entirely:

| Ending | Becomes | Examples |
|---|---|---|
| **-ant** | **-amment** | *constant → constamment*, *courant → couramment*, *puissant → puissamment* |
| **-ent** | **-emment** | *évident → évidemment*, *fréquent → fréquemment*, *récent → récemment*, *patient → patiemment* |

::: warning Both endings sound identical: /amɑ̃/
*constamment* and *évidemment* rhyme exactly. The spelling differs; the pronunciation does not.
This is the **-emment** rule from the vowels chapter, and it applies to this entire family.
:::

::: note lent is not in this group
*Lent* ends in **-ent** but is a plain adjective, not a present participle, so it follows the
basic rule: *lente* → ***lentement*** /lɑ̃tmɑ̃/. Compare *récemment* /ʁesamɑ̃/.
:::

## Irregular adverbs

A few common adjectives have adverbs that look nothing like them.

| Adjective | Adverb |
|---|---|
| **bon** | **bien** |
| **mauvais** | **mal** |
| **meilleur** | **mieux** |
| **petit** | **peu** |
| **rapide** | **vite** (or *rapidement*) |
| **gentil** | **gentiment** |
| **bref** | **brièvement** |

::: warning bon / bien and mauvais / mal
*Il est un **bon** chanteur* — adjective, describes the noun.
*Il chante **bien*** — adverb, describes the verb.

*C'est un **mauvais** film* — adjective.
*Il joue **mal*** — adverb.

Saying *il chante bon* or *il joue mauvais* is the single most common adverb error.
:::

::: note vite has no adjective
*Vite* is an adverb only. The adjective is *rapide*. So: *une voiture **rapide*** (a fast car)
but *il conduit **vite*** (he drives fast). *Rapidement* also exists and is slightly more
formal.
:::

## Where the adverb goes

| Structure | Position | Example |
|---|---|---|
| simple tense | after the verb | *Il parle **lentement**.* |
| compound tense, short adverb | between auxiliary and participle | *J'ai **bien** dormi.* |
| compound tense, long adverb | after the participle | *Il a répondu **poliment**.* |
| modifying an adjective | before it | ***vraiment** content* |
| commenting on the whole sentence | at the front, with a comma | ***Heureusement**, il est arrivé.* |

::: warning Never between subject and verb
English: *He **often** eats there.* French: *Il mange **souvent** là* — never *il souvent
mange*.
:::

::: examples
Il parle lentement. || simple tense
J'ai bien mangé. || short adverb, inside
Il a répondu immédiatement. || long adverb, after
Elle est vraiment gentille. || modifying an adjective
Heureusement, tout va bien. || commenting on the sentence
:::

## Alternatives to -ment

French often prefers a prepositional phrase where English would use an adverb — especially when
the *-ment* form would be long or clumsy.

| Instead of | French says |
|---|---|
| *silencieusement* | **en silence** |
| *rapidement* | **à toute vitesse**, **vite** |
| *joyeusement* | **avec joie** |
| *soigneusement* | **avec soin** |
| *heureusement* (lucky) | **par chance** |
| *régulièrement* | **de façon régulière** |

::: tip avec + noun and de façon / de manière + adjective
Two productive patterns:
- **avec** + abstract noun: *avec plaisir*, *avec soin*, *avec attention*.
- **de façon** / **de manière** + adjective: *de façon régulière*, *de manière évidente*.

Both are natural, and they let you form an adverbial idea for any adjective without worrying
about the suffix.
:::

## Common adverbs worth knowing whole

| Adverb | Meaning |
|---|---|
| **heureusement** | fortunately |
| **malheureusement** | unfortunately |
| **évidemment** | obviously |
| **apparemment** | apparently |
| **probablement** | probably |
| **certainement** | certainly |
| **absolument** | absolutely |
| **vraiment** | really |
| **seulement** | only |
| **également** | also, equally |
| **finalement** | finally, in the end |
| **actuellement** | currently — *not* "actually" |
| **éventuellement** | possibly — *not* "eventually" |
| **couramment** | fluently |
| **doucement** | gently, slowly |
| **tellement** | so much |

::: warning Three false friends in one table
**actuellement** = currently. For *actually*, use **en fait**.
**éventuellement** = possibly. For *eventually*, use **finalement**.
**couramment** = fluently. For *currently*, use **actuellement**.

*Je parle couramment français* means *I speak French fluently*, not *currently*.
:::

*Actuellement, je travaille à Paris.* || Currently — not "actually".

Translate: "Actually, I'm tired." || En fait, je suis fatigué.

:::
