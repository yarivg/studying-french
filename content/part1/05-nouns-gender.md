# Nouns and gender

Every French noun is masculine or feminine, including nouns for objects and abstractions.
There is no reasoning to be done about *why* a table is feminine; the gender is a property of
the word, and it controls the article, the adjective and sometimes the past participle.

::: rule Learn the article, not the noun
Never memorise *table*. Memorise **la table**. The article costs you one extra syllable and
saves you from guessing later. Every word in the vocabulary list in this course carries its
article for exactly this reason.
:::

## Endings that predict masculine

| Ending | Examples |
|---|---|
| **-eau** | *le château*, *le gâteau*, *le bateau*, *le manteau*, *le couteau* |
| **-ment** | *le paiement*, *le remerciement*, *le moment*, *le vêtement* |
| **-age** | *le nuage*, *le fromage*, *le visage*, *le voyage* |
| **-oir** | *le miroir*, *le couloir*, *le trottoir*, *le soir* |
| **-o** | *le vélo*, *le stylo*, *le piano*, *le numéro* |
| **-isme** | *le judaïsme*, *le tourisme* |
| **-ier** | *le papier*, *le calendrier*, *le quartier* |
| **-in** | *le jardin*, *le vin*, *le matin*, *le chemin* |
| **-ail** | *le travail*, *l'ail*, *le détail* |

::: warning -age and -eau exceptions
*la page*, *la plage*, *la cage*, *l'image*, *la nage* are feminine despite **-age**.
*l'eau* and *la peau* are feminine despite **-eau**.
:::

## Endings that predict feminine

| Ending | Examples |
|---|---|
| **-tion, -sion** | *la nation*, *l'attention*, *la question*, *la suggestion* |
| **-té** | *la liberté*, *la santé*, *la société*, *la vérité*, *la variété* |
| **-ure** | *la culture*, *la coiffure*, *la nourriture*, *la voiture* |
| **-ette** | *la fourchette*, *la chaussette*, *la serviette*, *la recette* |
| **-ance, -ence** | *la chance*, *la confiance*, *la dépendance*, *la science* |
| **-ie** | *la bougie*, *la pharmacie*, *la partie*, *la vie* |
| **-eur** (abstract) | *la peur*, *la chaleur*, *la douleur*, *la couleur*, *la fureur* |
| **-esse** | *la vitesse*, *la richesse* |
| **-ée** | *l'année*, *la journée*, *la soirée*, *la durée* |

::: warning -eur splits in two
Abstract **-eur** nouns are feminine: *la peur*, *la douleur*, *la couleur*.
**-eur** nouns naming a *person or machine* are masculine: *le professeur*, *le conducteur*,
*le moniteur*, *le chargeur*, *l'ordinateur*, *le sauveur*.

And *le bonheur*, *le malheur*, *l'honneur* are masculine exceptions to the abstract rule.
:::

## Nouns built from verbs

Nouns formed directly from a verb stem are masculine. This is a reliable little family:

::: examples
le regard || the look — from *regarder*
le baiser || the kiss — from *baiser*
le travail || the work — from *travailler*
le cri || the shout — from *crier*
le sourire || the smile — from *sourire*
le déjeuner || lunch — from *déjeuner*
le coucher de soleil || sunset — from *coucher*
:::

The same applies to any infinitive used as a noun: *le savoir*, *le pouvoir*, *le devoir*,
*le souvenir*.

## When you cannot see the gender

Before a vowel or a mute h, **le** and **la** both become **l'**, so the article stops helping.
These simply have to be learned as items.

| Masculine | Feminine |
|---|---|
| *l'arbre*, *l'argent*, *l'avion*, *l'ami* | *l'école*, *l'heure*, *l'eau*, *l'année* |
| *l'or*, *l'os*, *l'œuf*, *l'oiseau* | *l'île*, *l'âme*, *l'oreille*, *l'épaule* |
| *l'hôpital*, *l'homme*, *l'hiver* | *l'histoire*, *l'herbe*, *l'humeur* |

::: tip Force the gender to show itself
If you are unsure, put an adjective after it and see which form sounds right, or make it
plural and check whether you would say *un* or *une*: *un vieil arbre* → masculine;
*une vieille école* → feminine.
:::

## Words that change meaning with gender

A short list, but each pair is a genuine trap.

| Masculine | Feminine |
|---|---|
| **le livre** — the book | **la livre** — the pound |
| **le tour** — the turn, the trip | **la tour** — the tower |
| **le mode** — the method, mode | **la mode** — fashion |
| **le poste** — the job, the set | **la poste** — the post office |
| **le manche** — the handle | **la manche** — the sleeve |
| **le somme** — the nap | **la somme** — the sum |
| **le voile** — the veil | **la voile** — the sail |
| **le critique** — the critic | **la critique** — the criticism |

## People: making the feminine

| Pattern | Masculine | Feminine |
|---|---|---|
| add **-e** | *un ami* | *une amie* |
| **-eur** → **-euse** | *le chanteur*, *le serveur* | *la chanteuse*, *la serveuse* |
| **-teur** → **-trice** | *l'acteur*, *le directeur* | *l'actrice*, *la directrice* |
| **-ien** → **-ienne** | *le chien*, *l'italien* | *la chienne*, *l'italienne* |
| **-er** → **-ère** | *l'ouvrier*, *le boulanger* | *l'ouvrière*, *la boulangère* |
| no change | *le / la collègue*, *le / la bénévole*, *l'élève* | same word, article changes |

::: note Nouns that stay masculine for everyone
*le médecin*, *le professeur*, *le témoin* were historically masculine regardless of the
person. Modern usage — universal in Quebec and Belgium, increasingly common in France — adds
feminine forms: *la médecin*, *la professeure*. Both are current; neither will confuse anyone.
:::

## Plurals

| Rule | Singular | Plural |
|---|---|---|
| default: add **-s** | *le chien* | *les chiens* |
| already ends **-s, -x, -z**: no change | *le prix*, *le bras*, *le nez* | *les prix*, *les bras*, *les nez* |
| **-eau, -eu** → add **-x** | *le gâteau*, *le jeu* | *les gâteaux*, *les jeux* |
| **-al** → **-aux** | *le journal*, *l'animal*, *le cheval* | *les journaux*, *les animaux*, *les chevaux* |
| **-ail** → **-aux** (some) | *le travail* | *les travaux* |

Seven **-ou** nouns take **-x** instead of **-s**; the one you will meet is *le bijou → les
bijoux*. And three nouns are simply irregular: *l'œil → les yeux*, *le ciel → les cieux*,
*monsieur → messieurs*.

::: warning None of this is audible
*Le chien* and *les chiens* are both /ʃjɛ̃/. *Le gâteau* and *les gâteaux* are both /gato/.
Only the article tells a listener which you mean — so the vowel difference between **le** /lə/
and **les** /le/ is doing real work.
:::

::: exercise Le or la?
___ nation || **la** — **-tion** is feminine
___ château || **le** — **-eau** is masculine
___ liberté || **la** — **-té** is feminine
___ nuage || **le** — **-age** is masculine
___ voiture || **la** — **-ure** is feminine
___ plage || **la** — an exception to the **-age** rule
___ couleur || **la** — abstract **-eur** is feminine
___ conducteur || **le** — **-eur** naming a person is masculine
___ sourire || **le** — nouns from verbs are masculine
___ eau || **l'** — and it is feminine: *l'eau froide*
:::
