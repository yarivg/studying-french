# Prepositions

Prepositions are the part of a language least amenable to logic — French says *dans le train*
but *en avion*, and there is no deep reason. What follows is organised so you learn each one
with the situations it owns.

## à

Broadly: **to**, **at**, **in** — a point in space or time.

| Use | Examples |
|---|---|
| destination | *Je vais **à** la plage.* |
| location | *Il est **à** l'école.* · *Je suis **à** Paris.* |
| a point in time | ***à** 8 heures* · ***à** midi* |
| a range, with *de* | *de 8 heures **à** 9 heures* |
| playing a game or sport | *jouer **à** un jeu*, *jouer **au** football* |
| a defining feature | *une glace **à** la vanille*, *un homme **aux** yeux bleus* |
| purpose | *une machine **à** laver* |

Contractions: **à + le = au**, **à + les = aux**. *à la* and *à l'* stay as they are.

## de

Broadly: **of**, **from**, **about**.

| Use | Examples |
|---|---|
| origin | *Je viens **de** France.* · *Je suis **de** Paris.* |
| possession | *le livre **de** Marie* |
| topic | *Nous parlons **de** cinéma.* |
| material | *une table **de** bois* |
| starting point in time | ***du** lundi **au** jeudi* |
| after a quantity | *beaucoup **de** gens* |

Contractions: **de + le = du**, **de + les = des**.

## en

| Use | Examples |
|---|---|
| feminine countries | *Je vis **en** France.* · *Nous allons **en** Espagne.* |
| means of transport you sit *inside* | ***en** avion*, ***en** voiture*, ***en** train* |
| months | ***en** février*, ***en** août* |
| seasons — except spring | ***en** été*, ***en** hiver*, ***en** automne*, but ***au** printemps* |
| how long something takes | *Je l'ai fait **en** une heure.* |
| material | *une bague **en** or* |
| a state | ***en** retard*, ***en** colère*, ***en** vacances* |

::: warning en une heure vs dans une heure
***en** une heure* = it **took** an hour. *J'ai fini le travail en une heure.*
***dans** une heure* = an hour **from now**. *Je pars dans une heure.*
:::

## Cities and countries

This is a system worth learning as a block.

| Place type | Preposition | Examples |
|---|---|---|
| a city | **à** | *à Paris*, *à Tel-Aviv*, *à Rome* |
| a feminine country (most ending in **-e**) | **en** | *en France*, *en Italie*, *en Allemagne* |
| a country starting with a vowel | **en** | *en Israël*, *en Iran*, *en Espagne* |
| a masculine country | **au** | *au Canada*, *au Portugal*, *au Japon* |
| a plural country | **aux** | *aux États-Unis*, *aux Pays-Bas* |
| a street | **dans** | *dans la rue Dekel* |

::: examples
Je vis à Paris. || a city
Je vis en France. || feminine country
Je vis en Israël. || starts with a vowel
Je vis au Canada. || masculine country
Je vis aux États-Unis. || plural country
J'habite dans la rue Dekel. || a street
:::

::: note Coming *from* a place uses the same logic
*de* + city: *je viens **de** Paris*. *de* + feminine country: *je viens **de** France*.
*du* + masculine: *je viens **du** Canada*. *des* + plural: *je viens **des** États-Unis*.
:::

## Place prepositions

| Preposition | Meaning | Example |
|---|---|---|
| **dans** | inside | *dans l'autobus*, *dans la boîte* |
| **sur** | on top of, on | *le chat dort sur le sofa* · *elle travaille sur un projet* |
| **sous** | under | *le chien se cache sous la table* |
| **au-dessus de** | above (not touching) | *l'oiseau vole au-dessus de la maison* |
| **au-dessous de** | below (not touching) | *le pont passe au-dessous de la route* |
| **devant** | in front of | *le chien s'assoit devant la porte* |
| **derrière** | behind | *derrière la maison* |
| **entre** | between | *entre toi et moi* |
| **parmi** | among | *parmi les gens* |
| **chez** | at someone's place / firm | *chez Marie*, *chez le médecin*, *il travaille chez Google* |
| **près de** | close to | *près de la gare* |
| **loin de** | far from | *j'habite loin de la gare* |
| **à côté de** | next to | *à côté de l'école* |
| **en face de** | opposite | *en face du parc* |
| **à travers** | through | *à travers la porte*, *à travers la France* |
| **vers** | towards | *il marche vers la porte* |
| **autour de** | around | *autour de la table* |

::: warning sur means physically on
*Sur la table* — resting on it. For *about a topic*, French uses **de** or **sur** depending on
the verb: *parler **de** quelque chose* (talk about), but *un livre **sur** la guerre* (a book
about the war).
:::

::: note chez has no English equivalent
*Chez* means *at the home / premises / world of*. *Chez moi* (at my place), *chez le dentiste*
(at the dentist's), *chez Google* (at Google), *chez Proust* (in Proust's work). English needs
a different phrasing every time.
:::

## Time prepositions

| Preposition | Meaning | Example |
|---|---|---|
| **à** | at a clock time | *à 8 heures* |
| **avant** | before | *avant 8 heures*, *avant le cours* |
| **après** | after | *après 8 heures*, *après le cours* |
| **depuis** | since / for (still going) | *depuis 1980*, *depuis 2 ans* |
| **pendant** | during, for (a completed span) | *pendant deux heures* |
| **pour** | for (an intended span) | *je pars pour trois jours* |
| **dans** | in (from now) | *dans une heure* |
| **en** | in (duration taken) | *en une heure* |
| **jusqu'à** | until | *jusqu'à demain* |
| **dès** | from (as early as) | *dès demain* |
| **vers** | around (approximate) | *vers midi* |
| **il y a** | ago | *il y a une heure* |

::: rule il y a is also a preposition of time
Beyond *there is / there are*, **il y a** + a duration means **ago**:

*Il est parti **il y a une heure**.* — He left an hour ago.
*Je l'ai vu **il y a deux jours**.* — I saw him two days ago.

Depuis / pendant / pour / il y a get a full chapter in Part II, because English collapses
them all into *for*.
:::

## The remaining common ones

| Preposition | Meaning | Example |
|---|---|---|
| **pour** | for, in order to | *pour moi, c'est important* · *il achète un cadeau pour son ami* |
| **avec** | with | *il parle avec l'enseignant* |
| **sans** | without | *je suis sorti sans mon téléphone* |
| **par** | by, per, through | *il voyage par avion* · *trois euros par kilo* · *la route passe par la forêt* |
| **selon**, **d'après** | according to | *selon le journal* |
| **malgré** | despite | *malgré la pluie* |
| **sauf** | except | *tout le monde sauf moi* |
| **contre** | against | *contre le mur* |
| **grâce à** | thanks to | *grâce à toi* |
| **à cause de** | because of (negative) | *à cause de la grève* |

::: warning par avion vs en avion
***en** avion* = the mode of travel, from the traveller's point of view. *Je voyage en avion.*
***par** avion* = by air, as a channel — mostly for post and formal usage.

For everyday travel, use **en**: *en voiture*, *en train*, *en bus*, *en avion*. The exception
is anything you sit **on** rather than **in**: ***à** pied*, ***à** vélo*, ***à** cheval*.
:::

::: warning grâce à vs à cause de
Both mean *because of*, but they carry opposite loading.
***Grâce à** toi, j'ai réussi.* — thanks to you (good outcome).
***À cause de** toi, j'ai échoué.* — because of you (bad outcome).
:::
